## Projects

🎮 [Gameboi](https://tinyurl.com/gameboiz) 
> *An open-source generative AI tool that creates complete 2D games from text prompts using GPT-4, DALL·E, and PyGame.*

🧠 [StockSense](https://tinyurl.com/stocksenseplus)
